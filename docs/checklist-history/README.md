## How it grew

Diff the three surviving versions and the pattern is plain: every revision has been **additive, at the back**. The analytical core — the first six reviews (Analysis, Organization, Line-by-line, Read Aloud, Sensitivity, Sanity Check) — is unchanged, word for word, across all three. What grew were the later, more mechanical stages: Packaging and Presentation in v5, Publishing in v6.

The canonical current version is [`insights-report-checklist.md`](../../insights-report-checklist.md) (v6) at the repository root. A future v7 is in progress.
