# Issue Tracker — GitHub Issues

Issues for this repo live in **GitHub Issues** on [`lukewp/written-products-review-skill`](https://github.com/lukewp/written-products-review-skill/issues).

## CLI

Use the `gh` CLI to create, list, edit, and close issues.

```bash
# Create an issue
gh issue create --title "Title" --body "Body" --label "needs-triage"

# List open issues
gh issue list

# View an issue
gh issue view <number>

# Close an issue
gh issue close <number>
```

## External PRs

External PRs are **not** a triage surface. PRs are handled outside the triage state machine.
