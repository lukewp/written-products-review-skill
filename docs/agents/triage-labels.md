# Triage Labels

The triage skill moves issues through these five states via GitHub labels. Each role maps 1:1 to a label string.

| Role | Label string |
|------|-------------|
| Needs evaluation | `needs-triage` |
| Waiting on reporter | `needs-info` |
| Agent-ready | `ready-for-agent` |
| Human-ready | `ready-for-human` |
| Won't fix | `wontfix` |

To change a label string, edit this file — the triage skill reads it at runtime.
