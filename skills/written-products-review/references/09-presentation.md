# Review 9: Presentation *(conditional — decks only)*

*Derived from the checklist's "Ninth Review: Presentation (if applicable)."*

**Applicability gate.** Run this stage only if the product is a presentation/slide deck. If it is not, mark the stage **N/A** in the state and proceed to Stage 10 (if publishing) or finish. Do not skip silently — record N/A.

## Completion criteria — assess each

- [ ] **Font size floor.** No font sizes smaller than **20pt** if the deck is intended to support a speaker presentation (anything smaller is unreadable from a room).
- [ ] **Breathing space.** "Breathing space" for margin notes exists on all slides not intended to be full-bleed.
- [ ] **Consistent positioning.** Rulers/guides were used to keep recurring design elements (headers, page numbers, logos) in consistent positions slide to slide.
- [ ] **PDF delivery.** Delivered as **PDF**, not PPTX, so fonts and layout render identically on the reader's machine — and the final copy was compared side-by-side against the source to validate look-and-feel.

## How to run it

For an inspectable deck, check font sizes and element positions directly. For a described deck, convert these into a checklist the author runs against the source. Flag any slide that violates the font floor or lacks breathing space by slide number.

## Stage output — Presentation checks

```
## Review 9 — Presentation

- Font floor (≥20pt for speaker support): [pass / slides in violation]
- Breathing space: [pass / slides missing it]
- Consistent element positioning: [pass / fail — what drifts]
- PDF delivery + side-by-side validation: [done / to do]

**To fix:** [by slide number]
```

## Completion gate

Passes when the deck is assessed against all four items (or the stage is marked N/A for a non-deck), fixes are listed by slide, and the author confirms: proceed to Stage 10 (if publishing) or finish, or resubmit.
