# Review 5: Sensitivity Check

*Derived from the checklist's "Fifth Review: Sensitivity Check." Assess against the **brief** — who the reader is and who else may see the product.*

This stage protects the author and the organization from reputational and disclosure harm. Surface every flag; do not soften them away.

## Completion criteria — assess each

- [ ] **The newspaper test.** Does the product contain nothing that would be scandalous if a newspaper reported *"In its official research, Entity ABC determines XYZ"*? If it does contain that kind of assertion:
  - Are we **rock-solid** in the assertion? If not,
  - Has the assertion been tempered to be as accurate as possible, **and** has leadership been explicitly given a heads-up?
- [ ] **No embarrassing assertions.** Does the product contain no assertions that colleagues or clients might find embarrassing — the kind that would warrant a private briefing before broader release? (Or: has such a briefing already been given to all relevant parties?)
- [ ] **Marking.** Is the product appropriately marked based on its direct derivative citations of sensitive or classified materials?

## How to run it

For each potentially sensitive assertion, name it, state the risk, and state the required action — temper, brief leadership, mark, or (rarely) remove. This is a surfacing stage: the author and their leadership decide the disposition, but the skill must not let a flag pass unstated.

## Stage output — Sensitivity flags

```
## Review 5 — Sensitivity

Flags:
1. Assertion: "…"  Risk: [newspaper / embarrassment / marking]  Required action: [temper / brief leadership / mark / remove]  Confidence: [rock-solid? y/n]
Marking assessment: [appropriate / needs update — why]
Heads-up required to leadership: [yes/no — for which items]
```

## Completion gate

Passes when every sensitive assertion is flagged with its required action, marking is assessed, any required leadership heads-up is identified, and the author confirms: proceed to Stage 6, or resubmit.
